# Stage 5: Pull CD
GitHub-hosted Actions tests MariaDB, builds ARM64 and publishes SHA and main-ready tags. Ubuntu systemd polls main-ready and deploys its digest with existing rolling-update and rollback scripts. No self-hosted runner, Cloudflare Access token or Tailscale. This does NOT meet a mandatory GitHub Actions SSH deployment requirement; Actions success means publish, not production success. Docker Hub image must be publicly readable or server must have read-only registry authentication. Install on ubuntu via bash scripts/install-pull-cd.sh after copying scripts into VM. Secrets: DOCKERHUB_USERNAME and DOCKERHUB_TOKEN only in GitHub. Check journalctl -u memo-cd.service, ~/.local/state/memo-cd logs. Failed digest is not retried automatically; after diagnosis remove ~/.local/state/memo-cd/attempted and start service again. Existing DB and nginx are untouched. Do not redeploy stack to install timer. Single node, DB and nginx remain failure points. Test data persistence manually and actual rollback separately. Static checks only.
